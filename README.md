# AudioTx

Transmite el audio del teléfono Android 10+ a una PC con Windows por cable USB, sin VLC.

- Silencia el teléfono mientras está conectado y sus botones controlan el volumen de la PC.
- Receptor ligero para Windows 7 (`receptor32.exe` / `receptor64.exe`).
- Compila el APK y los `.exe` con GitHub Actions (pestaña Actions → Build → Run workflow).

Ver `LEEME.txt` para los pasos de uso.
